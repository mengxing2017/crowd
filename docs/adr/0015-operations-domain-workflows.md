# ADR 0015：数字调整、运营计划及用户告知的事务边界

日期：2026-10-29。状态：已实施，业务验收另行记录。接续 [ADR 0014](0014-domain-public-entrypoints.md)。

## 所有权

任务撤销依据、调减、恢复和批次属于 commissions；活动计划与统计属于 campaigns；消息、模板、授权及消息重试属于 notifications；工单与申诉属于 support；信号规则及风险处置属于 risk。没有重新建立 community 业务聚合。

domain 与 north 仅依赖本领域 south 的消费端口。south 适配器投影跨领域只读事实；任务撤销、申请暂停和数字争议使用提供方显式接口。各领域根入口仅导出 remote、south；没有新增事件目录或事件占位。

## 一致性

沿用现有 PostgreSQL 行锁事务：认证与对象授权、原请求幂等、任务处理、活动额度校验、风险记录、站内消息及审计统一提交。活动额度在领取结果尚未提交时验证，失败恢复原业务状态与幂等结果。

调减只针对原数字来源；申请占用及已登记结算不能直接调减。受影响申请标记为需核查，保留金额、经办和收款版本；已结算部分不自动追偿或抵扣未来数字。恢复必须关联已生效原调减。

外部通知单独持久化尝试，再释放事务锁调用通知端口，最后以尝试键记录结果。通知模板显式配置有限重试；失败不撤销已经提交的业务记录。仓库默认没有启用外部通知渠道。

## 兼容与交付

新状态使用 serde 默认值兼容历史 State，文件用途通过递增 migration 扩展。旧 HTTP 协议保留，新接口、TypeScript 契约和两端 feature 一起增加。`mod.rs` 只声明和导出；remote 按固定操作拆分，local 服务保持单一入口。

需求与操作细节见 [M20–M24 需求追踪](../requirements/m20-m24.md)和[岗位手册](../runbooks/m20-m24.md)。不设临时重构验证运行手册。
