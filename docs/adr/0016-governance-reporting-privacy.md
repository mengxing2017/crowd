# ADR 0016：安全、报表及隐私治理

状态：实现决策；不代替业务参数验收。

## 职责与事务

安全政策、会话再次验证与临时授权归 identity；报表、异步安全导出、差异及人工凭证核对归 reporting；分类保留、本人副本、注销核查与修复预检归 privacy。新 HTTP handler 使用固定用例，契约与两端 feature API 按同名领域归属，不扩展 community 门面。

platform 只协调共享认证、幂等、事务、审计与领域分派。报表及隐私新增状态提供 serde 默认值，兼容旧文档。修复通过 commissions 原批量调整管线，注销通过 identity 与 promotion 端口收回展示资料与推广入口；不在领域中依赖其他领域实现或 SQL。

## 审计与授权

审计摘要采用允许的编号、状态、版本及数字字段，不写完整收款载荷。数据库迁移保护已有审计前缀及状态删除，业务更正只能追加。再次验证与当前会话及安全政策版本绑定，权限校验仍逐请求执行；临时授权不能替代独立审批或扩大审批人的权限。

异步导出固定原快照，下载时再检查当前数据范围及有效期。本人副本白名单排除他人资料及内部凭据。资料清理先检查业务引用及保留策略，不能破坏历史收款快照、数字记录或争议保全。

## 任务事件与客户端兼容

外部任务成果通过 tasks 的事件入口与部署密钥适配器验签，业务时间与接收时间分开，按固定模板来源及执行窗口校验。去重和冲突审计在原状态事务中完成。来源停用不改变人工结算结果，不新增付款调度。

数组列表分页为可选扩展；旧响应形状保留。系统能力说明指导旧客户端继续查询原申请，小程序弱网重试继续使用原键及原内容。所有数字仍为业务标记，外部付款仍由人员线下执行。
