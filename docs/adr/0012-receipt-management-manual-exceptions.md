# ADR 0012：收款资料确认与人工异常处理

日期：2026-10-28。状态：已实施，正式政策配置与业务验收另行执行。需求依据：[M17–M19 追踪](../requirements/m17-m19.md)。

## 领域职责

收款资料的确认、版本、格式检查和清理保护归 `receipts`；私有二进制及按上传时间执行的删除归 `files` PostgreSQL 适配器。提现规则承载当前申请适用的支付宝格式、姓名及图像保留政策，沿用规则编制与独立发布流程，无默认正式政策。

`settlements` 拥有人工异常分类、责任人、处理限制及登记更正。`withdrawals` 固定申请收款快照及确认时间，`commissions` 继续维护占用与结转一致性。责任人指派只表示核查职责，不自动转移独占经办权。

## 一致性与兼容

默认资料由不可覆盖版本及停用事件推导。保存声明时记录服务端时间及声明版本；旧支付宝草稿需重新确认，不因政策发布自动升级。

清理使用与申请相同的共享状态事务锁，在锁内验证停用、全部历史引用、核查保全、显式保留期限，再在同一事务删除二进制并追加清理事件和幂等结果。保留资料元数据与审计，禁止删除申请快照。当前所有历史申请引用和该用户核查申请均保守保留，未引入未经确认的自动保全结束策略。

分类异常追加至申请事件，保留经办、类型、责任人、时间与说明。所有异常进入待核实并继续占用；资料错误和登记错误不能通过改成普通不明状态绕过核查。付款登记只记录外部人工结果，没有支付网关状态机。

新增命令为所属领域固定 handler，`mod.rs` 只声明及导出。旧 URL 和既有提交继续兼容；新校验拒绝未确认支付宝草稿申请是资料有效性修复。无新增 SQL migration；发布回退须保留能够识别新增事件及政策的版本。
