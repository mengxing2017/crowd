## 本地运行

```bash
devbox run -- make api-dev
make web-dev
make miniapp-dev
```

开发使用隔离嵌入式 PostgreSQL 17，自动执行 0001–0004 迁移。正常退出清理临时库，需持久化时按 [嵌入式 PG 手册](embedded-postgres.md) 使用外置开发库，禁止测试回退到业务数据库。

新建开发管理员可进入“产品目录与发布”“推广归因”。首次发布先由规则管理员明确配置归因窗口与首触／末触；由运营维护分类、上传产品图、保存草稿，配置任务完成条件、证据、规则版本、CNY 整数分佣金、规则有效期与提交时限，然后提交发布有效期。规则有效期必须覆盖发布有效期。需要第二位已授权人员以 `product_reviewer` 审核，不能自审；可使用独立微信测试用户，由身份审核人员为其授权相应岗位和对象范围。既有管理员升级不自动增权。

地区和资格有限制的产品，身份审核人员在“用户与权限 → 地区与资格核验”根据合法业务依据录入核验记录；用户领取不接受客户端自报地区或资格。没有相关数据处理依据时不要配置并采集此类限制。

小程序无需登录可浏览已发布目录，支持名称／分类／佣金筛选与排序。分享入口 `?source=码值` 先采集随机匿名触点，登录绑定；非法码展示回退说明和产品列表入口。用户查看关键条件、选择任务，主动确认后独立领取。领取结果和历史快照在个人页面展示。扫码本身不占名额，不生成数字佣金。当前不提供任务提交及佣金审核入口。

下架、紧急下架和归档立即阻断新领取，保留领取记录；待审或已批准历史内容不删除。重新上架和回滚都须重新提交及独立审核。定时生效、到期按请求服务端时间执行，30 秒 worker 更新站内通知和 revision；无外部微信订阅通知或付款任务。

## 接口

所有成功结果沿用 `{ data, request_id }`，业务错误沿用 `{ error: { code, message, request_id } }`。公开响应 `Cache-Control: no-store`，敏感资料不进入目录。新类型和 client 位于 `api-contract/src/modules/community/index.ts`，仅 feature 的 `api/index.ts` 引用契约包。

| 接口 | 用途 |
| --- | --- |
| GET `/api/v1/catalog` | 已生效产品；keyword、category、min_cents、max_cents、sort、task_status |
| POST `/api/v1/catalog/touches` | 匿名触点，只接受 code 和 scene，必须携带 Idempotency-Key |
| GET `/api/v1/catalog/images/{id}` | 仅在当前公开发布中被引用的 product_image；未发布／下架图片拒绝 |
| GET `/api/v1/community/read/catalog_admin` | 按岗位及产品范围查询草稿与发布历史 |
| GET `/api/v1/community/read/attribution_admin?target=*` | 归因审核范围内策略、访问数量及争议 |
| GET `/api/v1/community/read/attribution_policies` | 规则管理员查询策略版本 |
| GET `/api/v1/community/read/my_claims` | 本人领取及固定快照 |
| GET `/api/v1/community/read/my_attribution` | 本人已绑定访问摘要及申诉 |
| GET `/api/v1/community/read/catalog_notifications` | 本人站内通知 |
| GET `/api/v1/community/read/eligibility?target=用户编号` | 身份审核权限内的核验记录 |
| POST `/api/v1/community/files/product_image` | 运营上传产品图片，二进制 PNG/JPEG |

命令共用 `/api/v1/community/commands/{action}`，要求会话及 Idempotency-Key。动作：category_save、category_migrate、product_save、product_submit、product_review、product_offline、product_archive、product_rollback、policy_publish、touch_bind、task_claim、attribution_dispute、dispute_resolve、eligibility_verify。

修改对象命令须提交当前 version；新建为 0。领取须携带产品 id、release_id、task_id 及 confirmed=true，不接受用户、推广人、金额或地区字段。超时使用 `/read/command_result?target=原键` 查询，或同内容同键重试。匿名访问网络重试使用原访问键；新一次真实访问使用新键。完成事件仅内部 `record_verified_completion` 端口，来源验签适配器尚未接入，不开放普通用户提交完成归因。

## Web 分享落地

分享地址 `/?source=码值` 现在调用独立访问采集接口，同次请求重试（含 React StrictMode）复用请求键，真实刷新生成新访问键。匿名 Web 访问不自动关联已登录工作人员，也不消耗名额。失效码显示说明和“返回产品列表”，公开目录可直接通过 `/?catalog=1` 访问，不转入管理员登录或他人资料页。

Web 复制来源码后，在小程序填写来源码并登录时，小程序先记录合法访问，再随可信微信身份绑定触点；跨 Web／微信平台不会伪造身份或凭空绑定匿名浏览器会话。若要关联同一浏览器原触点，需另行实现可信跨端一次性凭证交换，本期未声称具备该能力。
