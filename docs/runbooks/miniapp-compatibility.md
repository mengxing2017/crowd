## 配置与构建

本地校验构建保留原命令，游客 AppID 和回环地址仅用于本地工程校验，不应上传为正式包：

```bash
pnpm --dir frontend --filter @crowd/miniapp build
```

复制 `frontend/apps/miniapp/.env.example` 为该目录下 `.env.production`，填写：

```dotenv
VITE_MP_WEIXIN_APPID=wx替换为真实小程序AppID
VITE_API_ORIGIN=https://替换为实际接口域名
VITE_PROMOTION_ORIGIN=https://替换为实际推广入口域名
```

变量也可从构建环境注入；环境变量优先于文件。`VITE_PROMOTION_ORIGIN` 必须与后端 `CROWD_PROMOTION_ORIGIN` 一致，允许双方一致的入口路径。`VITE_API_ORIGIN` 为 HTTPS 根域名，不带路径、查询或凭据。

```bash
pnpm --dir frontend --filter @crowd/miniapp build:release
```

该命令先预检，再编译，最后将实际 AppID 写入 `dist/build/mp-weixin/project.config.json`，保持域名校验开启。预检失败不会生成本次正式包；目录可能仍残留以前的构建，不能在命令失败后继续上传。构建成功也不验证 AppID 所有权、备案、证书或后台域名白名单。

平台后台还需核对：

1. request 合法域名覆盖 JSON 与原始二进制 POST；downloadFile 合法域名覆盖私有图片下载。图片等资源在不同域名时分别核对。
2. 《用户隐私保护指引》与实际能力匹配，覆盖相册／拍照、保存等实际使用范围；验证同意、拒绝和再次操作。不要求新增自定义隐私弹窗才能发布。
3. 普通链接二维码规则已配置并发布，链接跳到 `pages/index/index`，用后端实际生成的二维码核对 q 和推广触点。未引入新的 scene 码协议。
4. 明确受支持的微信／基础库版本范围；能力探测和兼容回退不替代最低版本真机验收。

## 恢复与隐私注意点

会话令牌继续只存内存。新增持久化键 `crowd.command-reference.v1` 仅存恢复引用及可选的 `withdrawal-original` 界面目标，按账号隔离。目标不进入服务端命令正文，不包含收款资料。网络结果不明保留原引用，原账号重新登录后查询；不支持拿其他账号查询原账号结果。服务端仍校验身份、资源及命令访问权限。

重启后不保存完整敏感请求，因此没有原内容时不提供盲目重试。若查询返回 RESULT_NOT_FOUND，不能据此认定原请求不会稍后完成；保留引用，先核对任务回执、申请和人工记录，再进行人工核查。不要清空恢复引用来强制第二次申请，更不能再次线下付款。

本地图片的 5 MiB、4096 像素检查仅匹配当前后端工程处理上限，避免读全图后才拒绝；不是新的正式业务政策。后端校验仍为最终依据。
