# M25–M29 运行与验证

## 配置与操作

管理端新增安全政策与临时授权、运营统计与记录核对、隐私治理入口。先由具备相应岗位及范围的人员发布政策，再使用相关业务。默认没有自动启用的保留期限、下载期限或高风险验证时长。

- 安全政策：明确再次验证动作与秒数，使用后台密码验证当前会话；政策换版使旧验证失效。临时授权填写成员、角色、数据范围及到期时间，由另一位具备相应权限的人员审批。
- 报表：填写起止时间和必要的产品／推广范围，查看快照中的水位、UTC 时区、分母和去重口径。审核通过仅算通过，不算已登记结算。
- 导出：填写用途及下载有效秒数，排队后刷新状态；下载重新校验当前权限。审计导出按 UTC 起止时间、业务对象及可选操作者过滤，仅白名单字段。
- 内部核对：指定用户生成核对记录；异常分派给有范围权限的审计人员。凭证核对必须人工确认金额、方式及原收款快照；结果不明保留本单占用，结案填写依据。
- 隐私：分类设置码图、证据、人工凭证及工单附件保留期，并保留必要历史与争议证据。文件仍被历史或当前业务引用时禁止清理。副本仅本人可读且有有效期；注销先核查未结事项，批准后清理展示资料、撤销推广码，保留必要数字及申请快照。
- 修复：先选择已有依据的调整单生成预检，由独立复核人员确认原影响清单；不直接写汇总。

## 可选任务来源

`POST /api/v1/task-events` 使用 `X-Task-Source` 和 `X-Task-Signature`，签名是原始 UTF-8 请求体的 HMAC-SHA256 小写十六进制值。来源编号限字母、数字与下划线，最长 64 字节。部署分别配置 `CROWD_TASK_SOURCE_<来源大写>_SECRET`（至少 32 字节）和 `CROWD_TASK_SOURCE_<来源大写>_WINDOW_SECONDS`（正整数）。不在业务表、日志、客户端或文档实例中保存生产密钥。

请求字段为 `event_id`、`claim_id`、`occurred_at`、`sent_at` 和可选 `base_cents`；整数时间以秒表示。发生时间不得晚于发送时间，发送时间必须处于配置的传输窗口，发生时间须符合原任务执行窗口，来源须与领取模板一致。同来源事件重放返回原结果，不同内容进入冲突核查。后台来源停用与收款资料、人工结算记录相互独立。此接口不是支付回调，也不确认官方到账。

迁移 0008 增加会话再次验证记录；0009 通过触发器保护已有审计前缀及状态记录；0010 补充历史注册整数时间。保持 forward-only，不删除历史记录回退。已有客户端无分页参数时仍获得原响应；数组列表可使用 `limit=1..200` 与上一页 `next_cursor`，按 `id_asc` 排序。原本返回分页对象的接口沿用既有分页参数，不能再套数组分页。
