# 四份方案需求追踪

依据：[01 业务范围与角色](../../report/01_业务范围与角色.md)、[02 用户注册与登录](../../report/02_用户注册与登录.md)、[03 个人资料与收款信息](../../report/03_个人资料与收款信息.md)、[04 个人独立推广码](../../report/04_个人独立推广码.md)。本表覆盖 40 条需求，记录本次实现与依赖边界，不修改原方案“待评审/待验收”的业务状态。

代码入口：`backend/src/community/`；两端 `features/community/api` 使用平台中立契约；小程序 `pages/index` 与 Web `Console/Landing` 提供页面。数据库 migration 0002。规则内容由运营提供，不把空配置或示例视为正式业务规则。

| 需求 | 本次编码对应 | 依赖、限制或未验收项 |
| --- | --- | --- |
| REQ-01-001 业务闭环定义 | rule_save/rule_publish：business_chain；历史版本保留 | 结算追溯须依赖后续任务、佣金和人工登记模块 |
| REQ-01-002 平台主体配置 | operator 版本配置、单一发布版本 | 历史业务记录的主体快照须由后续模块引用 |
| REQ-01-003 参与角色定义 | roles 配置；check_command_access/authorize 按角色和范围校验 | 岗位正式职责及分离策略待业务验收 |
| REQ-01-004 任务完成口径 | completion 版本与 product_tasks 完成口径/证据字段 | 任务证据执行服务不在本次范围 |
| REQ-01-005 平台审核口径 | review 版本；无自动付款入口 | 任务/申请审核与登记服务后续接入 |
| REQ-01-006 产品与任务关系 | product_tasks 目录，一个产品关联多任务，独立条件和证据 | 目录不提供完整产品展示或领取执行 |
| REQ-01-007 推广关系边界 | attribution 版本；注册来源与码归属独立记录 | 不启用多级分佣；任务归因需后续模块 |
| REQ-01-008 数字记录业务边界 | digital_boundary 发布强制 manual_only；无资金接口 | 业务闭环仍依赖后续任务与人工记录模块 |
| REQ-01-009 标记金额单位 | amount_unit 版本配置；整数分 display_cents 格式化测试 | 真实整数分计算与元展示由后续数字模块验证 |
| REQ-01-010 首期范围冻结 | release_scope 草稿/发布/停用；内容保留变更影响与待确认项 | 范围内容由运营填写，不代表业务已验收 |
| REQ-02-001 首次注册建档 | 可信身份唯一建档，原子安排主码生成任务 | 真实微信接入待凭据与真机验证 |
| REQ-02-002 微信身份登录 | WechatIdentity：服务端 code2Session；无客户端身份信任 | 自动测试注入端口，不替代微信官方联调 |
| REQ-02-003 手机号绑定 | phone 显式 FEATURE_NOT_ENABLED，不接受未验证号码 | 可选绑定渠道和控制权验证尚未启用 |
| REQ-02-004 协议主动同意 | 发布协议、用户主动同意、版本与时间留存 | 首次管理员运维初始化单独留 bootstrap 标记 |
| REQ-02-005 注册来源记录 | 合法且可用的来源码保留；非法来源不阻断注册 | 不生成佣金；任务归因尚未实现 |
| REQ-02-006 重复注册合并处理 | 同一平台身份恢复原账户；merge 人工核验申请 | 不因手机号相同合并；核验处理依赖后续流程 |
| REQ-02-007 登录会话续期 | 服务端期限、过期拒绝、重新登录；内存会话 | 任务草稿安全引用待任务模块接入 |
| REQ-02-008 退出登录 | logout 撤销当前会话；两端清理敏感内存 | 跨设备全量退出未启用 |
| REQ-02-009 账号限制提示 | restriction 范围/摘要/申诉说明；仅提现限制仍可查本人历史 | 实际提现控制由后续申请模块消费限制 |
| REQ-02-010 账号注销申请 | closure 保存待关联业务核查申请，禁止自动清除账户 | 任务/在途申请/争议检查依赖尚未接入，未完成注销闭环 |
| REQ-03-001 基础资料维护 | profile 乐观版本；昵称/头像变更不改身份与推广归属 | 真机页面体验待验收 |
| REQ-03-002 必要资料提示 | 收款资料不作为注册与推广操作前置 | 任务浏览/领取需后续任务模块验证 |
| REQ-03-003 收款资料分类 | 微信图片和支付宝账户独立字段、不同保存路径 | 支付宝草稿不宣称可申请使用 |
| REQ-03-004 微信码归属声明 | confirmed 主动声明；official_verified=false | 不宣称官方认证或账户可收款验证 |
| REQ-03-005 支付宝账户说明 | 支付宝账户草稿、姓名可选，不采集密码/验证码 | 支持账户形式及姓名必要性待确认 |
| REQ-03-006 手机号变更 | 手机号功能未启用，未验证的变更拒绝 | 控制权验证渠道待确认与接入 |
| REQ-03-007 资料版本管理 | receipt 追加新版本；receipt_disable 追加事件 | 旧版本不覆盖；提现快照引用待申请模块接入 |
| REQ-03-008 敏感资料访问 | 本人脱敏列表；完整查看需用途并审计；跨用户拒绝 | 后台完整访问待申请范围上下文接入 |
| REQ-03-009 头像文件处理 | avatar/wechat_receipt 用途、归属及真实文件校验 | 当前均私有保存，不借头像权限访问收款图 |
| REQ-03-010 资料纠错申请 | correction 保存待人工核实申请及受影响申请编号 | 停止线下处理/重新确认待人工结算模块实现 |
| REQ-04-001 注册自动生成 | 注册持久化生成任务；即时生成、后台队列重试及显式幂等恢复 | 故障后保留 pending 任务，重复重试仅生成一个有效主码 |
| REQ-04-002 推广码唯一约束 | 映射冲突拒绝覆盖，数据库行锁与码值/用户目标唯一索引保护创建 | 随机碰撞重新候选，不能改变原归属 |
| REQ-04-003 推广码查询展示 | 本人 codes、复制、私有二维码和用途说明 | 真机渲染与复制待人工验收 |
| REQ-04-004 二维码载荷设计 | 二维码仅编码 HTTPS 落地入口和不透明码 | 普通 Web 二维码，非微信官方小程序码 |
| REQ-04-005 推广码长期稳定 | 恢复已有身份、资料修改均不换码 | 除授权换发外保持主码稳定 |
| REQ-04-006 产品定向推广码 | code_create 校验已发布目录中的产品/任务后生成定向码 | 完整产品任务业务尚未接入 |
| REQ-04-007 码解析状态控制 | resolve 校验码、所属用户、限制和实时已发布目标目录 | 目录由有权运营维护，不推断完成或佣金 |
| REQ-04-008 推广码撤销换发 | code_rotate 版本/权限/范围、审批依据与原因；保留旧码 | 不修改历史来源，不影响后续已确认数字 |
| REQ-04-009 推广码下载保存 | PNG 二维码下载、相册保存；复制码值回退 | 拒绝相册授权的真机分支未执行 |
| REQ-04-010 推广码操作审计 | 生成/换发/查询审计记录可信操作者、请求号和规则版本 | 审批依据引用不等于外部审批系统验真 |

自动证据：`backend/tests/community_domain.rs`、`backend/tests/community_postgres.rs`、`backend/tests/http_contract.rs`、`api-contract/tests/community.mjs` 与共享 Rust/TypeScript 序列化样本。执行结果、环境与尚未验证事项见 [运行记录](../runbooks/m01-m04.md)。

## 管理员登录实现补充
