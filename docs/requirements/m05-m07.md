## 参数与依赖边界

- 归因窗口和首触／末触策略必须由规则管理员显式发布，无默认正式窗口。窗口从服务端访问时间起算，结束边界包含，完成事件还需按领取时策略再次检查。每个实例仅锁定一层直接推广来源。
- 每个任务版本明确自推策略、整数分佣金、CNY、规则有效期、提交时限，可选名额及活动计划数字上限；上限不是资金预占。工程允许零佣金，不替业务确定最低金额或正式运营策略。
- 名额与计划数字按产品＋模板编号累计包含历史发布版本的领取快照；本期不自动释放或重置。若需按活动独立额度，应配置独立模板编号并在任务／活动模块确认策略，不能改写旧领取。
- 本期实现独立领取确认和不可覆盖的产品、分类、模板、佣金规则、归因快照。任务提交、证据审核、佣金数字台账、撤销释放和人工结算依赖后续模块；未模拟这些模块成功。无支付接口、自动查单或付款调度。
- 产品内关联任务模板采用随发布固定的内嵌版本，包括完成条件和佣金规则。尚非 M08 的完整模板管理平台；发布时校验，存量任务仅使用原快照。
- 地区和资格限制使用身份审核人员根据业务依据录入的核验记录；无核验且产品有要求则拒绝领取，不信任客户端自报地区。无额外身份证采集、定位或第三方实名服务。
- 下架存量策略本期支持 `continue_existing`。终止未开始任务明确返回依赖未接入，不能仅改状态冒充已取消。回滚复制历史内容为新草稿，重新提交、独立审核及有效期校验后才能影响后续展示。
- 图片 PNG/JPEG、5 MiB、4096×4096、20 张为当前工程资源上限，非业务已确认资料限制；产品图与私有收款图严格分用途。审核为人工内容检查，未声称自动识别禁用内容。

## 权限

- `operator`：产品草稿、分类、提交、普通下架、归档、回滚；分类与新建需要 `platform` 或 `*`，已有产品按编号范围。
- `product_reviewer`：审核发布；禁止审核自己编辑或提交的版本。
- `product_emergency`：按产品范围紧急下架；缺风险编号／影响范围不能执行。
- `rule_manager`：发布归因策略；`attribution_reviewer`：范围内争议查询和裁定，不能裁定自己的申诉。
- `identity_reviewer`：按用户范围录入地区和资格核验历史，禁止核验自己。
- 普通用户只能领取本人任务、查询本人领取／通知；争议限任务执行人或原归属推广人。后端权限独立于页面菜单。
- 新建 bootstrap 管理员具有新岗位能力，但自审限制仍生效，需另一已授权用户审核。既有账户不会因升级自动增权，应由其他身份审核人员授权；不能修改自己的权限。
